BOOTSTRAP MODEL UNCERTAINTY ANALYSIS

Bootstrap repetitions: 10000
Random seed: 42
Confidence level: 95%
Out-of-sample series: 66

Method: paired, fold-stratified percentile bootstrap.
The same resampled series indices were used for all three models.
Resampling occurred separately within each temporal test fold, preserving each fold's contribution to the pooled evaluation.
No model was retrained and no features, hyperparameters, thresholds, or preprocessing were changed.
